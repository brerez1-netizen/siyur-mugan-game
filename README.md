# סיור בבניין המוגן

משחק כיתה בקבוצות לשיעור 18 בקורס תחיקת הבנייה (מרחבים מוגנים), אצל ארז ברוכי. יש גם דף תרגול אישי.

## הרעיון

שיטת ההוראה בסילבוס לשיעור הזה היא סיור לימודי במבנה עם מרחבים מוגנים. המשחק הוא הסיור הזה: בניין אחד מעורב שימושים, והקבוצות עולות בו קומה אחרי קומה בתפקיד הפקחים של פיקוד העורף.

בכל תחנה איור ונקודות ממוספרות. לכל נקודה כרטיס עם הנתונים שלה, והקבוצה מכריעה: **עוברת**, או **נפסלת, ובגלל מה**. בסוף כל תחנה הקבוצה רואה מיד מה עבר, מה נפסל, ואת העמוד בספר.

## איפה נבדקת התשובה

בטלפון, כמו ב-`milut-game`: כל קבוצה מתקדמת בקצב שלה וצריכה משוב בסוף כל תחנה. המשמעות היא ש-`gameData.js` קריא למי שפותח את קוד המקור. לכיתה זה מספיק, כי הניקוד של כל הקבוצות מוצג חי על המקרן.

**ערבוב האפשרויות**: כל האפשרויות מעורבבות, גם "עובר", לפי מזהה הקבוצה ומזהה הנקודה. אם "עובר" יושב תמיד ראשון, 14 הנקודות התקינות נפתרות בכפתור הראשון בלי לקרוא. רענון מחזיר את אותו סדר. בנתונים הסיבה הנכונה תמיד ראשונה, והערבוב הוא מה שמונע "התשובה תמיד א'".

## התמונות והמידות

**אף מידה לא מצוירת על האיור.** המידות כתובות בכרטיס של כל נקודה, והאיור רק מראה איפה הדבר נמצא. זה הכלל מ-`blitot-game` ומ-`negishut-game`: מודל תמונה לא מדייק במידות, ואיור שמראה קיר עבה יכול לסתור את הכרטיס. כאן יש סיבה נוספת: תחנה 6 משתמשת באותו איור עם מספרים אחרים.

המיקום של כל נקודה (`x`, `y` באחוזים) מכויל אחרי שהתמונה מגיעה. נקודה עם `x: null` היא נתון מהתיק בלי מקום באיור (הממ"ק בקומה אחרת בתחנה 6). כשתמונה חסרה, האיור מוחלף ברקע כהה עם שם התחנה, והמשחק ממשיך לעבוד.

## מקורות

כל המספרים מ"מדריך שימושי לתחיקת הבנייה" (גולן/דקל), פרק 24, עמודים 233-268, שנשען על מפרט פיקוד העורף לתכנון הנדסי במרחבים מוגנים. הפרק מחולץ ב-`context/מדריך-דקל/פרק-24-מרחבים-מוגנים.md` ב-workspace. עובי הקיר החיצוני של ממ"ד (25 ס"מ, עד 2 קירות חיצוניים) נבדק גם מול ריכוז ההנחיות של פיקוד העורף.

**בכוונה לא במשחק**: ערכים שהצילום שלהם בספר היה מטושטש (הזחת קירות בעמ' 237, 6 שעות ו-20% בממ"י בעמ' 254, סף חלון קדמי בעמ' 258), הוראת השעה לממ"ד בלי היתר (פקעה ב-25.10.24 לפי הספר), ותקני האש (755, 931, 921).

**בניית המשחק חשפה טעויות בתוכן השיעור באתר**, שתוקנו ב-17.9.2026: קיר חיצוני של ממ"ד נכתב 30 ס"מ, צינור ההכנסה בממ"ד 8 אינץ', קיר המגן 1.10 מ' בלי תנאי הדלת, ממ"ס עם חישוב לפי שוהה, שירותים שהותרו בממ"מ וטיח גבס שנאסר.

## Firebase

פרויקט Realtime Database נפרד, `erez-mugan-game`, עם כללי `.read`/`.write` פתוחים קבוע (`database.rules.json`). מבנה:

```
game:  { state: lobby|tour|review|finished, startedAt, endedAt, review }
teams: { <id>: { name, color, joinedAt, at, finishedAt, ans: { <stationId>: { <spotId>: "pass"|"r0"|"r1"... } }, sub: { <stationId>: ts } } }
```

"איפוס עמוק" במסך המרצה מוחק את כל הקבוצות ואת כל התשובות. כדאי להריץ אותו בין מחזורי הוראה ולפני שיעור אמיתי.
